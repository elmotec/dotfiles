# Global Codex instructions

## Approval for mutating commands

Package names and installation requests may be discussed without executing
commands.

Do not run install, update, remove, publish, or dependency-changing commands
(`npm`, `npx`, `pip`, `uv`, `cargo`, etc.) without first showing the exact
command and asking for confirmation immediately before execution.

A package mention or request for instructions is not authorization to mutate
the workspace or system.
